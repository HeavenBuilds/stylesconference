# Styles Conference Website

A beginner front-end web development project built while following Shay Howe’s *Learn to Code HTML & CSS* lessons.

## About the Project

Styles Conference is a fictional web design and development conference website. The project provides hands-on practice with building and styling web pages using HTML and CSS.

## What I'm Learning

- Writing semantic HTML
- Styling web pages with CSS
- Working with typography, colors, and spacing
- Creating page layouts and navigation links
- Organizing website files and stylesheets
- Building a multi-page website

## Technologies Used

- HTML5
- CSS3

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser to view the website.

## Learning Resource

This project is based on lessons from Shay Howe’s *Learn to Code HTML & CSS*.
